Check & Update Data (डेटा जाँचे & बदलें)

ID Card production se pehle data validation aur correction sabse mahatvapurna step hai:

  1. Data Upload: Sahi formats me excel/data file aur student photos upload karein.
  2. Pending List Check: Upload ke baad pending list me jaen aur columns check karein. Agar koi error/galti ho to use yahin thik (Edit) karein.
  3. Move to Verified: Data aur photo sahi check karne ke baad unhe select karke Move to Verified karein.
  4. Final Approval: Verified list me review complete karne ke baad records ko Approve karein. Approve hone ke baad hi cards print ke liye ready hote hain.
Checklist Before Approve: Name, Class, Section aur Roll number matching check karein. Student ki photo centered aur clear honi chahiye.

Check & Update Data

Data validation and correction before ID card production is the most critical step:

  1. Data Upload: Upload excel data files and student photos in the correct formats.
  2. Pending List Check: Check the pending list after uploading. If there are any mistakes or validation errors, edit and fix them there.
  3. Move to Verified: After checking that the data and photos match correctly, select the records and click Move to Verified.
  4. Final Approval: Review the verified list, then Approve the records. Cards are ready for print/download only after approval.
Checklist Before Approve: Double check Name, Class, Section, and Roll numbers. Ensure the photo is clear, centered, and belongs to the correct student.

Reprint कैसे करें

Adarsh ID Cards system me reprint process bahut simple hai. Agar kisi card me correction ki zarurat hai to niche diye steps follow karein:

  1. Dashboard par header me Reprint card par jaen.
  2. Request Reprint button click karke card select karein aur reprint request submit karein.
  3. Aap status check karne ke liye Request List ya Confirm List dekh sakte hain.
  4. Reprinted cards download karne ke liye Download List ka upyog karein.
Important: Reprint sirf genuine correction ya card damage hone par hi karein, aur har reprint ka sahi reason record karein.

How to Reprint

The reprint process in Adarsh ID Cards is simple. If a card needs a correction or reprint, follow these steps:

  1. Go to the Reprint section in the dashboard header.
  2. Click the Request Reprint button, select the card, and submit the request.
  3. You can view the status of requests in the Request List or Confirm List.
  4. Use the Download List to download completed reprint cards.
Important: Use reprint only for genuine correction or physical card damage cases, and always record the correct reason.

Create Assistant (सहायक बनाएं)

Apne work load ko share karne ke liye aap apne staff members ke liye assistant user accounts bana sakte hain:

  1. Dashboard par sabse upar Quick Actions me New Assistant button par click karein.
  2. Ek side drawer open hoga. Usme Assistant ka Name, Username aur Password bharein.
  3. Assign Permissions & Tables: Assistant ko jin-jin ID card groups ya classes ka access dena hai, unhe select karein.
  4. Assistant user apna alag account login karke data upload aur correct kar sakta hai, par final approval right sirf Client Admin ke paas hota hai.
Tip: Har staff member ke liye alag assistant account banayein taaki activity track ki ja sake. Kabhi bhi passwords share na karein.

  • Data Upload: Enabled.
  • Pending Records Correction: Enabled.
  • Move to Verified: Enabled.
  • Card Approval and Export: Disabled (Client Admin only).

Create Assitent

To share your workflow, you can create assistant user accounts for your team members:

  1. Click the New Assistant button in the Quick Actions section at the top of the dashboard.
  2. A side drawer will open. Enter the Assistant's Name, Username, and Password.
  3. Assign Permissions & Tables: Select the specific ID card groups or classes the assistant is allowed to access.
  4. The assistant can log into their own account, upload data, and make corrections, but final approval rights remain with the Client Admin.
Tip: Create a separate assistant account for each staff member to track their activity. Never share passwords.

Assistent Permissions Overview

  • Data Upload and File Import: Enabled.
  • Pending Records Modification: Enabled.
  • Move to Verified Queue: Enabled.
  • Card Approval & Printing Export: Restricted (Only Client Admin).
